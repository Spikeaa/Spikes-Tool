#### OSINT tool combining many existing tools into one combined platform to enhance the usability and accessibility of said tools, accessable through a web browser.


------------


Featuring a GUI for the tool **Sherlock** and many other tools related to OSINT integrated into a web GUI, made for a university project.

------------


Tools incorporated:



##### People Search:

truepeoplesearch.com
familytreenow.com
thatsthem.com
searchpeoplefree.com


------------


##### Facial / Image:

facecheck.id
pimeyes.com

------------



##### Username / Social:

github.com/sherlock-project/sherlock

------------



##### Breach Search:

haveibeenpwned.com
breachdirectory.org
snusbase.com
dehashed.com
osint.industries
leakcheck.io
leakpeek.com

------------






##### Crypto:

blockchain.info

------------



##### Miscellaneous:

exifinfo.org

------------



This software has been developed and tested on Linux:

To use this tool, input these commands into the Linux terminal to install necessary packages:

------------


sudo apt install python3

sudo apt install python3-pip

sudo apt install git

Sudo apt install python3.8-venv

pip install Flask

pip install Flask Pillow exifread

------------


After this go to the directory of this project in the terminal and type:

------------


python3 app.py

------------


After this, navigate to the web address:

------------


http://127.0.0.1:5000/people

------------


Now you can use the tool!
